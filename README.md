# 最小真实数据项目 starter

starter 不含问题数据，也不替你选择任务。先在最终项目 README 写项目句子、两个例子和数据契约。

## 本项目定义（方案 A：用身体与位置信息预测场均得分）

> 本项目是**表格回归**（课程 A 模式）：用球员"进入联盟前可知"的身体与位置信息，预测其单赛季场均得分，并在同一条件下比较简单基线与线性回归。

### 项目句子

> 我们要帮助【球队数据分析师】，根据【球员的身高、体重、年龄、位置】，预测【该球员某赛季的场均得分】，以便【在考察/签约前快速得到一份粗略的得分期望】；我们尤其不能忽略【身体信息对得分解释力有限时，模型给出看似精确实则误导的数字】。

### 任务类型判定

选择 **A 模式：表格预测（回归）**。理由：输入是一行结构化字段，输出是连续数值（场均得分）。刻意只用"选秀前可知"的特征，避开未来信息泄漏；不需要配对数据集，比"预测新秀首赛季"简单得多，可在课程时间内验证。

### 立项七项（逐项确认，任何一项不清楚就先缩小）

1. **使用者与场景**：球队数据分析师在考察球员前，想快速得到一个大致的得分期望，用于初步排序与决定"谁值得进一步深挖"。
2. **实际目标**：根据可获得的静态信息（身高/体重/年龄/位置）估计场均得分，帮助决定先看哪些人。
3. **一条样本**：`all_seasons.csv` 中一行 = 一名球员在某赛季的记录（含身体字段、位置、场均得分等）。
4. **输入**：球员身高、体重、年龄（进入联盟前就可知，无泄漏）；**不使用同赛季的其他统计**（助攻、命中率、出场数等，避免"用结果预测结果"）。注：该数据集版本没有位置列，若日后找到含位置的版本可加入作为类别特征。
5. **目标输出**：场均得分（连续数值，单位：分/场）。
6. **成功与错误**：核心指标 = 平均绝对误差 MAE（预测与真实得分的平均差距）；对使用者最致命的错误 = **系统性高估或低估**（例如永远给高分球员低分），会导致漏掉或高估球员。
7. **使用边界**：只提供粗略得分期望，不预测伤病/潜力/团队适配；对模型解释不了的球员（技术流、体系依赖）标注"依据不足，需人工复核"。

### 两个例子

**例子 A（普通）**
- 输入：身高 201cm、体重 104kg、年龄 22、位置 前锋
- 期望输出：预测场均得分 12.4（并给出误差范围或说明）
- 为何有用：分析师无需看录像，先有一个数量级概念

**例子 B（失败/边界）**
- 输入：身高 185cm、体重 82kg、年龄 24、位置 后卫，真实场均得分 28.1（远高于模型预测）
- 期望输出或拒绝：模型给出低预测，脚本把它标为"预测误差最大的案例"，提醒"身体信息无法解释其得分，需人工复核"
- 主要风险：把模型预测当作精确值，忽略身体数据无法捕捉的技术/体系因素

### 基线与候选

- **基线**：全体训练球员的平均场均得分（最简单可解释）。
- **候选**：随机森林回归——用身高/体重/年龄 + 选秀轮次/顺位 预测场均得分（比基线复杂一步，可读特征重要性）。
- **评估**：固定随机种子 42 的 80/20 划分，同一测试集上比较 MAE；结果保存到 `results/summary.txt`。
- **实测**：基线 MAE 4.877，候选 MAE 3.053，**降低 37.4%**；特征重要性排序为 draft_number > player_weight > age > player_height > draft_round。

```powershell

python main.py
```


预期：数据契约单测全部通过（文件存在、行数、必需字段、pts 数值、落选值清理）。
